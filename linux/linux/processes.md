# Linux Processes

## Что такое процесс

**Процесс** — это запущенная программа, которая выполняется в операционной системе.

Каждый процесс имеет:

- PID — идентификатор процесса;
- владельца;
- приоритет;
- состояние;
- потребление CPU и RAM.

## Основные команды

### Просмотр процессов

```bash
ps aux
Интерактивный просмотр
top

или:

htop
Поиск процесса
ps aux | grep <process>
Завершение процесса
kill <PID>

Если процесс не завершается:

kill -9 <PID>
Troubleshooting процессов

Если система работает медленно:

Проверить загрузку CPU через top или htop.
Найти процессы с высоким потреблением ресурсов.
Проверить использование памяти через free -h.
Проверить логи проблемного приложения.
При необходимости перезапустить процесс или сервис.
Общий алгоритм

Проблема → Найти процесс → Проверить ресурсы → Проверить логи → Исправить → Проверить результат
