# Linux Troubleshooting

## 1. Определение проблемы

**Цель:** понять, что именно не работает.

- Что произошло?
- Когда появилась проблема?
- Воспроизводится ли ошибка?
- Какие изменения были сделаны перед появлением проблемы?

## 2. Проверка состояния системы

| Что проверяем | Команда |
|---|---|
| CPU и процессы | `top`, `htop` |
| Память | `free -h` |
| Диск | `df -h` |
| Процессы | `ps aux` |
| Сервисы | `systemctl status` |

6. Пример Troubleshooting

Проблема: веб-сервис недоступен.

Проверка
systemctl status nginx
journalctl -u nginx
ss -tulpn
curl localhost
Алгоритм решения
Проверить статус сервиса.
Посмотреть логи.
Проверить открытые порты.
Найти причину ошибки.
Исправить проблему.
Повторно проверить работу сервиса.
7. Общий алгоритм

Проблема → Проверка → Логи → Поиск причины → Исправление → Повторная проверка
