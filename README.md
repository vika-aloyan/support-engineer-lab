# Support Engineer Lab

Учебный практический проект для развития навыков Support Engineer и Information Security.

## Skills

- Linux
- TCP/IP
- DNS
- HTTP/HTTPS
- SQL
- Docker
- Git
- Zabbix
- Monitoring
- Troubleshooting
- Incident investigation

## Что изучаю и практикую

- диагностику проблем в Linux;
- анализ сетевых соединений;
- диагностику HTTP/HTTPS-запросов;
- работу с SQL;
- анализ логов;
- мониторинг состояния сервисов;
- поиск причин инцидентов;
- работу с Docker-контейнерами.

## Практические сценарии

В проекте разбираются типовые ситуации, с которыми может столкнуться инженер поддержки:

- сервис возвращает HTTP 500;
- DNS не разрешает доменное имя;
- на сервере заканчивается место на диске;
- сервис работает медленно;
- пользователь получает HTTP 401/403;
- сервис недоступен;
- необходимо найти причину ошибки по логам.

## Цель проекта

Практическое развитие навыков для работы Support Engineer и дальнейшего развития в области информационной безопасности.
